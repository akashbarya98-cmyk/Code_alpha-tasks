# 🧮 Calculator Web App

A simple and responsive calculator built using HTML, CSS, and JavaScript.  
This project performs basic arithmetic operations and provides a clean user interface with real-time results.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear screen (C button)
- ⌫ Delete last input
- ⌨️ Keyboard support
- ⚡ Real-time calculation
- 📱 Responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
